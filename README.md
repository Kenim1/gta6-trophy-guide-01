An offline GTA 6 trophy guide and tracker for all 55 PlayStation 5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze): every trophy with its official name, description and grade, a cited guide in our own words, a checklist saved in the browser, export/import, filters, a spoiler setting, a roadmap to the platinum, and missable flags.

Entry for the [make.fun bounty “Build the best GTA 6 trophy guide”](https://make.fun/bounty/gta6-trophy-guide-01).

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
```

Or open `app/index.html` in desktop Chrome — the app is plain static files and works with the network off. Progress is saved in localStorage; export and import it from the checklist page.

## Build the dossier

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/dossier.json
```
